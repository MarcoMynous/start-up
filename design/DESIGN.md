## Brand & Style

The design system establishes a high-performance visual language tuned for high-stakes competitive programming. The identity operates at a precise ratio: **70% disciplined developer product** and **30% competitive/cyberpunk tension**. It is engineered to evoke the focused intensity of an elite terminal environment combined with the electric pressure of esports telemetry.

### Tone & Demeanor
- **Surgical & Quantitative:** The aesthetic is driven by real runtime telemetry, Elo deltas, test-suite execution states, memory profiling, and match IDs. Zero decorative fluff, no pseudo-hacker matrix rain, no cartoon trophies, and no synthetic binary noise.
- **Controlled Cyberpunk Tension:** Atmospheric depth is generated through near-black carbon substrates, ultra-crisp borders, and restrained high-contrast luminescence.
- **Relentless Efficiency:** Prioritizes dense data display, instant visual parseability, and zero latency friction for hyper-focused engineers.

### Style Archetype: Precision Command Center
A fusion of dark technical minimalism and industrial brutality. Interfaces use deep layered dark surfaces (`#080A0B` to `#171B1F`), hairline mechanical dividers (`#23292D`), and deliberate, explosive moments of Volt luminescence (`#E4FF3F`) reserved strictly for high-stakes state changes and decisive actions.

## Colors

The color palette is calibrated around a disciplined monochrome foundation punctuated by surgical status signals. Most screens are composed entirely of obsidian, graphite, muted carbon borders, and crisp off-white text.

### Color Hierarchy & Discipline
- **Background (`#080A0B`):** Deep abyssal canvas serving as the void foundation.
- **Surfaces (`#0D1012`, `#12161A`, `#171B1F`):** Progressive structural elevation layers used to compartmentalize telemetry panels and workspaces.
- **Primary Accent / Volt (`#E4FF3F`):** High-energy kinetic spark. Volt must remain scarce. It is strictly reserved for primary call-to-actions, active navigation markers, queue state triggers, selected control toggles, and rating milestones. It is never applied to general body text or persistent card boundaries.
- **Technical / Runtime Cyan (`#22D3EE`):** Designated exclusively for system-level telemetry: execution runtimes, memory profiles, network latency, compiler versions, and telemetry streams.
- **Status Indicators (`#22C55E`, `#EF4444`, `#F59E0B`):** Explicit semantic feedback for test executions, match victories/defeats, and warnings. Never used as ambient decorative fills.
- **Text Scale (`#F3F5F2`, `#8A9297`, `#596166`):** Engineered for high contrast against carbon backdrops, maintaining total legibility during high-stress matches.

## Typography

Typography acts as an interface partition between human narrative and machine telemetry.

### Font Roles
- **Geist (Primary UI):** Powers structure, system headings, descriptive copy, interactive labels, and general dashboard flow. Neutral, sharp, and razor-focused.
- **JetBrains Mono (Telemetry & Code):** Powers all system metrics, execution numbers, Elo scores, timers, memory readouts, match IDs, test case matrices, and system metadata headers.

### Rules of Engagement
- **Mono Eyebrows:** Major modules must lead with an uppercase monospace eyebrow formatted with telemetry delimiters (e.g., `MATCH // 0x4F92`, `ARENA // RANKED 1V1`).
- **Tabular Figures:** Monospace metrics guarantee rock-solid alignment during real-time countdowns and live telemetry streams without horizontal layout shift.
- **Proportional Discipline:** Sub-12px micro-type is strictly banned for operational metrics to prevent cognitive strain during high-stress competition.

## Layout & Spacing

The layout philosophy rejects cramped, centered SaaS templates in favor of broad, full-width asymmetric command consoles utilizing 92% to 96% of the available display real estate.

### Grid & Viewport Architecture
- **Fluid Grid Engine:** 12-column adaptive fluid layout with a base `1.25rem` (20px) gutter and dynamic outer gutters (`2.5rem` on desktop, scaling to `1rem` on mobile).
- **Asymmetric Proportions:** Core operational layouts prioritize functional weight. For example, in live battle mode: Problem specs occupy ~26%, Editor claims ~52%, and Opponent Telemetry commands ~22%.
- **Vertical Freedom:** Content breathes with natural, unrestricted vertical scrolling. Screen density is achieved through condensed layout modules, never through forced single-viewport trapping.

### Breakpoints & Adaptive Strategy
- **Desktop (1440px+):** Expanded telemetry command center, multi-panel split view, floating expandable dock at bottom edge.
- **Laptop (1024px–1439px):** Panel proportions compress smoothly, horizontal gutters tighten to `1rem`, dock height remains anchored.
- **Tablet (768px–1023px):** Secondary telemetry stacks beneath primary workspaces; auxiliary charts collapse into segmented tabs.
- **Mobile (<768px):** Complete reflow to a unified vertical stream. Data tables transform into stacked metric cards. Touch target minimums strictly enforce `48px` tap envelopes. Hover-dependent interactions are completely stripped.

## Elevation & Depth

Depth in this system is achieved via **structural tonal layering** combined with **subtle precision outlines**, rather than simulated drop shadows or heavy blur physics.

### Layer Hierarchy
1. **Canvas Substrate (`#080A0B`):** Lowest foundational plane.
2. **Surface Tier 1 (`#0D1012`):** Primary panel chassis and large operational module wrappers.
3. **Surface Tier 2 (`#12161A`):** Interactive cards, code execution containers, terminal panes, and data table headers.
4. **Surface Tier 3 (`#171B1F`):** Hover states, active tabs, floating popovers, and elevated telemetry tags.

### Boundary Definitions
- Surfaces are separated by hairline 1px mechanical borders (`#23292D`).
- Elevation is communicated by border luminescence shifts rather than diffuse shadows. When an active interactive card is hovered, its border steps from `#23292D` to `#353E45`.
- **Neon Blur Prohibition:** Ambient diffuse neon glows are prohibited. High-stakes focus elements (like an active matchmaking queue) may feature a razor-sharp, constrained 1px perimeter glow (`0 0 12px rgba(228, 255, 63, 0.15)`), eliminating visual noise while underscoring tension.

## Shapes

The geometry reflects tight industrial hardware tooling. Radii are intentionally kept disciplined, ranging between `8px` and `12px` to prevent the software from appearing bubbly, casual, or non-serious.

### Geometry Rules
- **Base Components (Inputs, Buttons, Tags, Badges):** Standardized at `8px` (`roundedness: 1` tier). Delivers a clean, crisp, modern edge profile.
- **Operational Panels & Modules:** Standardized at `10px` to `12px`.
- **Corner Discipline:** No full-pill geometry (`9999px`) on primary action buttons; pill shapes diminish the severe technical precision of the tool. Floating navigation docks use constrained `12px` or `16px` outer radiuses.
- **Progress Bars & Gauges:** Flat end caps (`0px` or `2px`), referencing mechanical LED instrumentation readouts.

## Components

### Buttons
- **Primary Tactical (Volt CTA):** Filled `#E4FF3F` background, dark ink text (`#080A0B`), `Geist` medium weight, height `48px` (desktop up to `54px`), radius `8px`. Hover shifts to `#F0FF70`. Active state contracts subtly (`scale(0.99)`).
- **Secondary System:** Surface 2 background (`#12161A`), 1px border (`#23292D`), primary text (`#F3F5F2`). Hover steps to Surface 3 with border `#353E45`.
- **Destructive / Abort:** Border and text `#EF4444`, background `rgba(239, 68, 68, 0.06)`. Hover enhances background fill to `rgba(239, 68, 68, 0.14)`.

### Floating Bottom Navigation Dock
- **Architecture:** Fixed floating pill-dock anchored `28px` from viewport bottom. Surface `#0D1012` with 1px border `#23292D`. Height `60px`.
- **Interaction Engine:** Resting desktop state displays icons only. On hover or focus, the hovered destination reveals its label with an elastic slide expansion (`200ms ease-out`). Active destination features a Volt indicator mark and subtle background wash.
- **Mobile Paradigm:** Dock becomes a persistent bottom bar with static icon-plus-label configurations; hover-reveals are disabled.

### Metric Strips & Telemetry Displays
- Replaces generic KPI cards with an edge-to-edge compact data strip (`Surface 1`).
- Internal divider borders (`1px solid #23292D`).
- Key metrics feature a `system-eyebrow` label atop a `JetBrains Mono` numerical read-out, accompanied by trend deltas (`↑ 12`, `↓ 4`, or `—`).

### Data Tables & Match Archives
- **Layout:** Dense, border-bottom rows without vertical cell dividers.
- **Row Interaction:** Hover invokes Surface 2 wash. Result cells leverage bold monospace tags (`VICTORY` in `#22C55E`, `DEFEAT` in `#EF4444`).
- **Telemetry Readability:** Runtimes, memory, and Elo changes are strictly right-aligned and rendered in JetBrains Mono.

### Code Editor & Terminal Workspaces
- Obsidian code cavity (`#080A0B`) isolated by 1px `#23292D` border.
- Integrated test case drawer featuring distinct pass/fail status tabs: green check indicators for passed test suites, red cross badges for runtime failures.
- Non-blocking execution state displays: Compiling, Executing, Finalizing.

### Form Inputs & Selectors
- Background `#0D1012`, border `#23292D`, text `#F3F5F2`.
- Focus state: Border shifts to Volt (`#E4FF3F`) with zero external fuzzy ring, preserving absolute vector sharpness. Placeholder text rendered in `#596166`.
